# Система авторизации JWT

## 🎯 Обзор

Система авторизации на основе JWT токенов успешно интегрирована в frontend приложение. Пользователи могут регистрироваться, входить в систему и получать доступ к защищенным страницам в зависимости от своей роли.

## 🔐 Компоненты системы

### 1. AuthContext (`frontend/contexts/AuthContext.tsx`)
- **Назначение**: Центральное управление состоянием авторизации
- **Функции**:
  - `login(email, password)` - вход в систему
  - `register(email, password, name, role)` - регистрация
  - `logout()` - выход из системы
  - `checkAuthStatus(token)` - проверка валидности токена

### 2. Страницы авторизации
- **`/login`** - страница входа в систему
- **`/register`** - страница регистрации
- **`/unauthorized`** - страница для неавторизованных пользователей

### 3. ProtectedRoute (`frontend/components/ProtectedRoute.tsx`)
- **Назначение**: Компонент для защиты маршрутов
- **Возможности**:
  - Проверка авторизации
  - Проверка ролей пользователя
  - Перенаправление на страницу логина

### 4. API функции (`frontend/lib/api.ts`)
- `loginUser(credentials)` - вход через API
- `registerUser(userData)` - регистрация через API
- `getCurrentUser(token)` - получение данных пользователя
- `createAuthenticatedRequest(token, url, options)` - создание авторизованных запросов

## 👥 Роли пользователей

1. **admin** - Администратор (полный доступ)
2. **hr** - HR-менеджер (управление вакансиями и кандидатами)
3. **university** - Представитель университета (ограниченный доступ)

## 🛡️ Защита маршрутов

### Пример использования:
```tsx
// Защита страницы для всех авторизованных пользователей
<ProtectedRoute>
  <MyComponent />
</ProtectedRoute>

// Защита страницы только для HR-менеджеров и администраторов
<ProtectedRoute requiredRole="hr">
  <HRComponent />
</ProtectedRoute>

// Защита страницы только для администраторов
<ProtectedRoute requiredRole="admin">
  <AdminComponent />
</ProtectedRoute>
```

## 🔄 Жизненный цикл авторизации

1. **Загрузка приложения**: Проверка токена в localStorage
2. **Вход**: Получение JWT токена и сохранение в localStorage
3. **Авторизованные запросы**: Добавление токена в заголовки
4. **Выход**: Удаление токена и перенаправление на страницу логина

## 🚀 Использование

### Регистрация первого пользователя:
1. Перейдите на `/register`
2. Заполните форму (email, пароль, имя, роль)
3. После регистрации автоматически войдете в систему

### Вход в систему:
1. Перейдите на `/login`
2. Введите email и пароль
3. После успешного входа перенаправление на главную страницу

### Доступ к защищенным страницам:
- Все основные страницы защищены авторизацией
- Доступ зависит от роли пользователя
- Неавторизованные пользователи перенаправляются на страницу логина
